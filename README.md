# Ключ ВК для комбайна

Одна страница мини-приложения ВКонтакте: запрашивает у ВК ключ доступа пользователя с правом `photos`
(через `VKWebAppGetAuthToken`) и кладёт его в буфер обмена.

Ключ показывается только владельцу страницы и никуда не отправляется: здесь нет ни сервера, ни аналитики,
ни сторонних запросов, кроме библиотеки VK Bridge. Секретов в репозитории нет.

Используется вместе с приватным инструментом (`python -m combine.cli vk token`).
